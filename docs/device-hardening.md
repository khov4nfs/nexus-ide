# v0.5.1 device hardening and Google account sign-in candidate

## Evidence from owner device testing (2026-11-27)
iPhone 16 Pro, iOS 27.2.1, SideStore-signed unsigned native and Ubuntu Integrated builds. Owner reported native saved file survives app restart. Screenshots showed aarch64, glibc 2.39, Ubuntu 24.04.5 LTS, interactive shell commands, guest /tmp file read/write returning 42, PTY stty 24 80 -> 33 111, and final report closed=true, error=null, exitCode=0, ok=true, shutdownClean=true, termSignal=0. Exact installed commit not independently matched from device. Ctrl-C, forced stop, MCP, AGY and OpenVSCode not verified on device. Screenshots also show severe letterboxing, multiline paste collapse and smart punctuation.

## Changes
- Generated UILaunchScreen enabled in all three XcodeGen targets; packaging rejects missing launch screen. Fullscreen needs installation/launch verification on device (iOS can cache launch metadata). No ignoresSafeArea workaround.
- UIKit multiline terminal command input with smart quote/dash/insert/delete, autocorrection and capitalization disabled; normalize CRLF/CR to LF, send bounded batch with final newline. Still plain-text PTY, not a full ANSI emulator.
- Explicit Google sign-in with original reviewed AGY ELF, using documented agy acp --login --disable-telemetry in a PTY. Same boot, HOME and worker; no API key or custom OAuth client. Only complete HTTPS accounts.google.com /o/oauth2/auth or /o/oauth2/v2/auth links containing client_id and state offered, native URL validation before Safari launch. SecureField input, single bounded code submission, cancellation, 180s login timeout, then ACP initialize and session/new. No raw login output, token export, password entry or reverse-engineered endpoint. Login code retained in memory as literal filter during session; no comprehensive token DLP. Google chat and fixed smoke enabled after login process success, not proof of model access. Reviewed native edit proposal remains API-key-only. Existing deny-only policy and 3 turns/capture limits unchanged. Idle timeout 180s.
- Disposable guest auth cache is controlled by original CLI and may use guest storage; try removal after verified shutdown and stale trial cleanup on next Agent boot. No persistent Google token import, Keychain OAuth storage or cross-launch login guarantee. Background suspension during Safari, Linux keyring/DBus support, URL shape and actual original AGY behavior need physical verification. If official CLI emits a different or wrapped URL, fail closed rather than relax host checks. Not a security sandbox.
- Synthetic CI fixture checks login PTY -> code -> marker -> ACP same guest -> session/new -> fixed response -> clean shutdown. No Google account, actual AGY, actual OAuth or model execution in fixture. CI trace sentinel check; no raw login failure log published. Existing build/permission/credential gates retained.

Official references (verified 2026-11-27): https://antigravity.google/docs/ide/extensions/acp/ ; https://antigravity.google/docs/install ; https://developer.apple.com/documentation/technotes/tn3208-preparing-your-apps-launch-screen-to-meet-app-store-requirements

## Device steps after new unsigned IPA CI passes
Install via existing SideStore; preserve native workspace by using same installer and bundle identity when updating. Verify fullscreen. Import independently reviewed official Linux ARM64 AGY binary and SHA-256 from Files. Choose Sign in with Google; confirm consent, open Safari from the offered button, sign in to Google, return with the code and submit. Do not share code, URL or token file. Create session, run fixed smoke OR up to three chat turns. Check cancellation and close. If login fails, record only redacted status; no auth code, URL or raw logs. Use API key fallback if compatible. GitHub Actions packaging and owner-reviewed distribution remain unchanged.

## Release blockers
This is a device test candidate, not production certified. Real Google login, model call, login cache protection, iPhone fullscreen/terminal update, MCP tool execution, direct ACP tool grants, full ANSI, OpenVSCode/LSP/extensions, automatic hooks, additional harnesses and Docker/full VM remain incomplete or unverified. No public proprietary binary, no remote runtime.
